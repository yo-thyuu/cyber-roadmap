# Linux Notes



\## Commands I know (no lookup needed)

- `ls` — list files (ls -alh: human readable) 

- `cd` — change directory (../.. or the absolute path or relative path to navigate)

- `cat` — read file

- `echo` — print text 

- `pwd` — where am I

- `mkdir` — make folder

- `rmdir` — remove folder

- `touch` — create empty file

- `rm` — delete file

- `cp` / `mv` — copy / move

- `grep` — search in text

- `man` — help

- `which`/`whereis`/`whoami`  — search/find/identify

- `sudo` — please give me root access for this bash


## Commands I'm learning

- `chmod` — permissions (rwx)

- `ps` — list processes

- `awk` — column extraction

- `cut` — cut columns

- `sort` / `uniq` — sort / remove duplicates

- `head` / `tail` — first/last lines

- `strings` — extract readable text from binary



## Concepts

\- File system: / (root), /home, /etc, /var, /tmp

\- Permissions: owner/group/other × r/w/x

\- Pipes: `command1 | command2` (output of 1 → input of 2)

\- Redirect: `>` (overwrite), `>>` (append)
